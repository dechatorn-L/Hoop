# Project Rules & Guidelines

## ⚡ Agent Response Style (Caveman / Ultra-Concise)
- **Be extremely concise and direct.**
- **No greetings, polite preambles, conversational filler, or apologies.**
- **Do not repeat the user's question or explain self-evident concepts.**
- **Focus strictly on file edits, commands run, terminal results, and next actions.**
- **Use concise bullet points and direct technical statements.**
