แนะนำหลัก (Cloud)

1. Roboflow v4 (people_basketball_hoops/4)

🎯 คลาส: rim, basketball, person
  • ข้อดี: เสถียรสูงสุด มีคลาสคน ช่วยแยกแยะผู้เล่นกับลูกบาสไม่ให้สับสน
  • ข้อเสีย: ต้องต่อเน็ตและใช้ Roboflow API Key
  • เหมาะสำหรับ: เล่นทั่วไป สนามมาตรฐาน มีคนยืนใต้แป้น
แนะนำออฟไลน์ (เร็วสุด)

2. Local ONNX: Swish-Vision (11.7 MB)

🎯 คลาส: basketball, rim, sports ball
  • ข้อดี: ออฟไลน์ 100% Fine-tuned จากชุด Basketball-1 ล็อกเฉพาะลูกบาส ไม่ตีกรอบรวมกับคน (30–60 FPS)
  • ข้อเสีย: ขนาดโมเดลเล็ก เหมาะกับระยะใกล้ถึงปานกลาง
  • เหมาะสำหรับ: ซ้อมยิงเดี่ยว เล่นกลางแจ้ง ประหยัดแบตเตอรี่สูงสุด
ใหม่ล่าสุด (Attention C2PSA)

3. Local ONNX: YOLO11s Basketball (36.2 MB)

🎯 คลาส: rim, ball, player (9.4M Params)
  • ข้อดี: สถาปัตยกรรม YOLO11 ล่าสุด สกัดภาพลูกบาสที่เคลื่อนที่เร็ว (Motion Blur) และสภาวะแสงย้อนกลางแจ้งได้ดีเยี่ยม
  • ข้อเสีย: ขนาด 36.2 MB ต้องการ GPU ระดับปานกลางขึ้นไป
  • เหมาะสำหรับ: เล่นกลางแจ้ง ชู้ตลูกเร็ว สภาพแสงเปลี่ยนแปลง
Open-Vocabulary AI

4. Local ONNX: YOLO-World (47.8 MB)

🎯 คลาส: basketball, basketball rim, person
  • ข้อดี: Zero-Shot AI แยกแยะวัตถุด้วยภาษา ลดปัญหาความสับสนกับพัดลมหรือหลอดไฟในห้อง 100%
  • ข้อเสีย: ใช้หน่วยความจำ VRAM ปานกลาง (~300MB)
  • เหมาะสำหรับ: พื้นที่ที่มีสิ่งกีดขวางหรือวัตถุรบกวนเยอะ
ออฟไลน์ (แม่นยำสูงระดับโปร)

5. Local ONNX: Pro High-Precision (42.7 MB)

🎯 คลาส: Basketball, Rim (YOLOv8s 11.1M Params)
  • ข้อดี: โมเดล YOLOv8s ขนาดใหญ่ ความละเอียดสูง เหมาะกับการชู้ตระยะไกล 3–8 เมตร
  • ข้อเสีย: ขนาดไฟล์ใหญ่กว่า (42.7 MB)
  • เหมาะสำหรับ: คอมพิวเตอร์ / สมาร์ตโฟนที่มีชิป GPU แรง (เช่น Xiaomi 13)
เฉพาะบุคคล

6. Roboflow Custom Model ID

🎯 คลาส: ตามโมเดลที่คุณเทรนเองบน Roboflow
  • ข้อดี: แม่นยำสูงสุดสำหรับสนามของคุณเอง (Fine-tune 100-300 รูป)
  • ข้อเสีย: ต้องมีบัญชี Roboflow และถ่ายรูปเทรนเอง
  • เหมาะสำหรับ: สนามที่มีสภาพแสงหรือทรงแป้นบาสแปลกตา
